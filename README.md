# MedCore Docs

Центральная документация проекта MedCore.

Этот репозиторий хранит продуктовый, архитектурный и контентный контекст проекта и служит единой точкой входа для разработчиков и AI-агентов.

## Структура

- `product/` — идея продукта, MVP, roadmap.
- `architecture/` — архитектура системы и модель данных.
- `content/` — структура учебного контента и процесс его подготовки.
- `decisions/` — архитектурные и продуктовые решения (ADR).
- `ai/` — краткий актуальный контекст для AI-агентов.

## С чего начать

1. Прочитать `ai/context.md`.
2. Затем `product/mvp.md`.
3. Для разработки — `architecture/overview.md` и `architecture/database.md`.
4. При изменении важного решения добавить новый файл в `decisions/`.

## Принцип документации

Документация должна описывать не только **что** мы делаем, но и **почему** было принято конкретное решение.
